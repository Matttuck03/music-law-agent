Stricter option: upload the knowledge pack

The link route has ChatGPT read these pages as it goes. Uploading the pack instead puts every topic, claim and source into a shared ChatGPT Project, where it can search the full text each time.

Set up a shared Project in five steps

  1. Download music-law-pack.zip and unzip it.
  2. In ChatGPT, open Projects in the sidebar and create a new project, for example "Music law".
  3. Open the project's instructions and paste the short instruction below.
  4. Add every unzipped file to the project.
  5. Share the project, choose "Anyone with a link", and send that link to the team. Everyone asks their questions in chats inside the project.

Short instruction for the project

You are a music-law research assistant for a team building a user-friendly, DJ-style app for mixing existing songs, fed by a stem splitter. Answer only from the files in this project; start with 00-START-HERE.md and open the card that matches each question. Cite claim ids like [M-0123] and name the source. If the files do not cover it, say "not in my files" and do not fill from memory. Say what is unsettled, flag what needs a licensed music attorney, and give the "Law last checked" date. Never say that changing a song enough makes it yours, that crediting the artist makes it fine, that a set number of seconds is fair use, that a cover licence covers a remix, or that not selling it makes it legal. You are a research tool, not a lawyer; this is not legal advice.
